# Security policy

This project handles private key material. **Do not report a vulnerability, seed phrase, private key, vault password, or API key in a public issue.**

Until a security contact is configured, open a private GitHub Security Advisory against the repository. Include a minimal reproduction, affected version, impact, and remediation suggestion. Rotate any exposed secret immediately.

The project does not promise that a generic software wallet is safe against a compromised host, malicious dependencies, clipboard theft, phishing, or unsafe transaction approval. Integrators must perform independent audits before handling real funds.
